1. Install addon (`matrix_vX.X.X.mcaddon`)

> [Related guide](https://support.aternos.org/hc/en-us/articles/360042095232-Installing-addons-Minecraft-Bedrock-Edition)

2. Configure the server properties file

```properties
texturepack-required=true
op-permission-level=2
server-authoritative-movement="server-auth-with-rewind"
```
> [Link to server.properties](https://aternos.org/files/server.properties)

3. Enable **Beta API**
> [Related guide](https://support.aternos.org/hc/en-us/articles/4407553257873-Enabling-experimental-gameplay-Minecraft-Bedrock-Edition)
