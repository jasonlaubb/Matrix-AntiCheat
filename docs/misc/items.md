# Matrix special items

This page will show you how to get and use the custom item.

If you want to craft the item, you can also type `/function getUwuMaterial` to get all the materials directly!

# Basic tool

1. Matrix UI Panel

You can get this by typing `/give @s matrix:itemui`.

You can also craft this item by crystal of uwu and redstone block in **Uwu craft table**

*RIGHT CLICK: Run `-matrixui` command*

2. Mod Hammer

You can get this by typing `/give @s matrix:mod_hammer`.

You can also craft this item by amethyst shard and Matrix UI Panel in **Uwu craft table**

*RIGHT CLICK: Select player to apply moderation action*

*LEFT CLICK: Select the player you hit to apply moderation action*

3. Crystal of Uwu

You can get this item by typing `/give @s matrix:crystal`.

You can also craft this item by **bedrock**, pink wool and amethyst shard in crafting table.

This item can be used to make Matrix items.

4. Uwu craft table

You can get this item by typing `/give @s matrix:uwu_craft_table`.

You can also craft this item by crystal of uwu, bedrock and crafting table in crafting table.
