## ***Generate key***
1. Go to the release and download the `Matrix-vX.X.X.mcaddon`
2. Rename it into `Matrix-vX.X.X.zip`
3. Open it and open the file `BP\scripts\data\config.js`
4. Edit the config.js in the editor to the config you think it is the best.
5. Go to the generator website: [CLICK ME](https://jasonlaubb.github.io/Matrix-AntiCheat/gen.html)
6. Paste the **all** of the text to the textbox.
7. Click the `Convert json string to key` button.
8. Click the `Copy whole string` button.
## ***Export key***
1. Run the `-export` command.
2. Use google lens to scan the message.
3. Delete the `-` sign
## ***Import key***
1. Go to the generator website: [CLICK ME](https://jasonlaubb.github.io/Matrix-AntiCheat/gen.html)
2. Paste the whole key in the textbox
3. Click the `Split key to the input-able part` button
4. Go to game and run `mset` command
5. Input different part into the ui by splitting it to different part (if it is too long)
